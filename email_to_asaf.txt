💻 הוראות הרצה מקומית:
אם תרצה להריץ את הקוד מקומית על המחשב שלך, ניתן לעשות זאת בכמה שלבים פשוטים:

1. שכפול הריפוזיטורי (Clone):
   git clone https://github.com/AlonHrtmn/pockemon_game_asignment.git
   cd pockemon_game_asignment

2. הרצת שרת ה-API:
   * נווט אל תיקיית השרת:
     cd pokemon-backend
     dotnet run
   * השרת יתחיל להאזין בכתובת http://localhost:5088.
   * הערה: כברירת מחדל, השרת מוגדר להתחבר למסד הנתונים המרוחק ב-Supabase. אם תרצה להריץ אותו בצורה מקומית ומבודדת לחלוטין ללא תלות ברשת, פתח את קובץ ה-appsettings.json ושנה את "DatabaseProvider" ל-"Sqlite". טכנולוגיית EF Core תייצר אוטומטית קובץ pokemon.db מקומי ותבנה את ה-Schema (טבלאות ואילוצים) עם עליית השרת.

3. הרצת ממשק הלקוח (Frontend):
   * פתח טרמינל חדש ונווט אל תיקיית הלקוח:
     cd pokemon-frontend
     npm install
     npm start
   * פתח את הדפדפן וגלוש לכתובת: http://localhost:4200

📋 תכונות מרכזיות והדגשים (גרסה 1.0):
* החלפת מסד נתונים דינמית ומיידית: הארכיטקטורה מאפשרת החלפה מהירה של ספק בסיס הנתונים (PostgreSQL / SQLite / MS SQL Server) על ידי שינוי הגדרה פשוט בקובץ ה-JSON (appsettings.json), ללא צורך בשינויי קוד (Code Changes).
* זיכרון מטמון בצד השרת (Caching): נבנתה ארכיטקטורת מטמון (Cache) בצד השרת. בסיס הנתונים משמש כפרוקסי (Proxy) מול ה-PokeAPI החיצוני כדי למנוע את איטיות השרתים החיצוניים ולהבטיח שליפת נתונים מהירה במיוחד.
* אילוצי שלמות נתונים (Integrity Guardrails): הוגדרו אילוצים קשיחים על מספר חברי הצוות (עד 5 פוקימונים), מניעת כפילויות של יצורים בצוות, ומנגנון נקי להחלפה מהירה של פוקימון בתוך סלוט (Slot) פעיל.
* מאמן AI חכם (AI Team Coach): מנגנון ניתוח מבוסס חוקים (Rule-based analyzer) ב-C# המחשב את כיסוי סוגי האלמנטים של הצוות, ממוצעי הסטטיסטיקות, מאפיין את סגנון המשחק של הצוות (למשל: Speed Blitzers, Balanced Vanguard) ומציע המלצות טקטיות מותאמות אישית.
* מנגנון שרידות והתאוששות מתקלות (Fallback Modes): המערכת מטפלת במצבי אי-זמינות של בסיס הנתונים (מעבר אוטומטי ל-SQLite מקומי עם הצגת באנר התרעה בממשק) ובמצבי אי-זמינות של ה-API החיצוני (ייצור נתונים דטרמיניסטיים מבוססי Seed מקומי וטעינת תמונות מ-GitHub CDN).
* ממשק משתמש מתקדם (UI/UX): עיצוב HUD עתידני ייחודי הכולל זכוכית מטושטשת (Glassmorphism), הילה זוהרת ברקע, רספונסיביות מלאה, עדכוני ממשק אופטימיים (Optimistic Updates) לביטול השהיית רשת בעריכת הצוות, וכפתורי ניווט צפים למעלה/למטה עם תמיכה בלחיצה ארוכה (Hold-to-Scroll).
